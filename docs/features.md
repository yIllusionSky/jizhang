# 功能与规则

- 首页汇总人民币折算总资产，列出各钱包名称、原币金额和更新日期。点击钱包整行进入编辑。
- 钱包名称为 1–40 个字符；每个钱包固定人民币或美元。金额非负，最多两位小数，单钱包最多 999,999,999.99。
- 初始余额属于初始资产，不计收入。
- 记收入增加余额及收入统计，收入必须大于零。
- 设置余额低于原余额，差额计支出；高于原余额，差额计余额校正。余额校正不计收入。设置未变化的余额不新增流水。
- 同日以最后一次操作余额为最终余额，各笔收入、支出、校正全部累计。没有操作的日期沿用前值。
- 日／月／年／总计显示人民币折算收入、支出、收支结余。资产趋势最多显示 32 个采样日期；只有一天时显示最终余额。收支柱图比较所选期间的收入与支出。
- 初始资产、余额校正、汇率影响分别显示，因此资产变化与收支结余可能不同。
- 汇率每天在启动或前台跨日时请求，失败保留缓存；休市日正常使用最近交易日报价并显示报价日期。设置页支持重试。
- 钱包详情右上角可改名；仅更改名称，币种、余额、流水保持不变。
- 设置页可导出完整 JSON 备份，包含钱包、流水、历史汇率和外观。通过系统文件选择器导入，预览并确认后替换整个账本，不合并记录；可恢复上一次导入前的账本。
- 钱包详情右上角可删除钱包，确认后永久删除该钱包及其全部流水，统计随之重算；其他钱包保持不变。
- 浅深色外观保存在本地。当前没有修改历史流水、跨设备同步、后台定时唤醒。
