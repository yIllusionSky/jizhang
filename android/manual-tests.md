# Android 手动测试

前置：安装最新 APK，启动 `app.jizhang.wallet/.WalletActivity`。仅在测试模拟器上操作，使用独立测试钱包。

1. 首页新建人民币钱包“日常零钱”，初始余额 1000。首页总额增加 1000，统计收入仍为 0。
2. 点击首页钱包整行，选择“记收入”，输入 200。预览余额 1200；保存后余额 1200。
3. 再选择“设置余额”，输入 900。预览支出 300；保存后当日统计收入 200、支出 300、结余 −100、余额 900。
4. 另一钱包初始 1000，设置为 1200。新增余额校正 200，收入不变。
5. 切换日／月／年／总计，检查日期、选中状态、图表和初始资产分离。连续多日操作后资产折线需沿用未更新日余额。
6. 在设置同步汇率，检查报价日期。创建美元钱包并检查原币余额与人民币折算。关闭网络后重试，显示失败并保留旧报价。
7. 重启应用，钱包余额、流水和外观保持。切换深色，检查系统栏、输入框、按钮和图表对比度。
8. 名称输入中文和 40 个字符，金额输入最大值。输入空金额、负数、三位小数与超限金额，不得保存；错误靠近金额框展示。
9. 打开与关闭中文键盘，并用系统键盘的数字布局输入金额，检查创建按钮可见、输入可滚动，返回键先收键盘，再返回首页。切换输入框后数字仍能输入。
10. 空账本与无收支数据时显示空状态。滚动长内容，底部导航保持固定。

调试构建可用 `adb exec-out run-as app.jizhang.wallet cat files/wallets-v1.json` 检查持久化结果。不要把截图中测试金额当作实际账户数据。

11. 点击钱包详情右上角“删除”，确认框显示名称和历史记录删除提示。取消后钱包不变；再次确认删除后回首页，钱包和关联统计消失。重启后仍保持删除，其他钱包不受影响。
12. 首页不显示汇率数值或“更新”按钮。钱包名称过长时截断，金额完整展示。删除全部钱包后仍可添加新钱包。

发布验证：推送版本 tag 后查看 Android Release workflow；成功后 Release 应含签名 ARM64 APK 和 SHA256SUMS.txt。下载并验证签名，安装到独立测试设备；后续版本应能覆盖安装并保留记录。
